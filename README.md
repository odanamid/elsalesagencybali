# BaliGrow – One-Page Website

Professional one-page website for **BaliGrow**, a digital growth agency that helps product and service businesses in Bali increase online sales through Instagram, Google, Shopee, Tokopedia, TikTok Shop, and WhatsApp.

---

## Features

- Modern, clean, and professional design (Navy blue theme)
- Fully responsive (mobile, tablet, desktop)
- Smooth scroll animations
- Animated counters
- Sticky navigation with scroll effect
- Floating WhatsApp button
- Contact options:
  - WhatsApp
  - Email
  - Google Calendar booking
- Clear call-to-actions throughout the page
- Fast loading (pure HTML + Tailwind CSS via CDN)

---

## How to Use (Local)

1. Download or copy the `index.html` file
2. Open the file in any modern browser (Chrome, Edge, Firefox, Safari)
3. That’s it — no installation or build process required

---

## Customization Guide

### 1. Change WhatsApp Number
Search for `6281234567890` and replace it with your real number (example: `628123456789`).

### 2. Change Email Address
Search for `hello@baligrow.id` and replace it with your real email.

### 3. Add Google Calendar Booking Link
1. Go to [Google Calendar](https://calendar.google.com)
2. Create an **Appointment schedule**
3. Copy the booking page link
4. Replace every `YOUR_BOOKING_LINK_HERE` with your real link

### 4. Update Content
You can freely edit:
- Agency name
- Headlines
- Services
- Package prices
- Stats numbers
- Footer text
